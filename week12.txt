REQUIREMENTS :
• Two computers
• Ethernet cable / common Wi-Fi network
• Windows operating system
• Command Prompt
PROCEDURE :
Step 1 - Connect the computers
Connect both computers to the same:
• Wi-Fi network, or
• LAN/Ethernet network
Step 2 - Find the IP address
On both computers, open Command Prompt and execute:
ipconfig
Note the IPv4 Address
For example:
Computer 1 → 192.168.1.10
Computer 2 → 192.168.1.11
Step 3 - Check the subnet
The subnet mask should normally be the same, for example:
255.255.255.0
Step 4 — Test connectivity
From Computer 1, execute:
ping 192.168.1.11
From Computer 2, execute:
ping 192.168.1.10
If the connection is successful, the output will contain:
Reply from 192.168.1.11
This confirms that the two computers can communicate.
Step 5 — Verify network information
Use:
ipconfig /all
This displays detailed information such as:
• IP address
• Subnet mask
• Default gateway
• MAC address
• DNS server


PYTHON CODE:

server.py:

import socket

# Create socket
server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# Bind IP address and port
server.bind(("127.0.0.1", 5000))

# Listen for client connection
server.listen(1)

print("Server is waiting for connection...")

# Accept client
conn, address = server.accept()

print("Connected to:", address)

# Receive message
message = conn.recv(1024).decode()
print("Client:", message)

# Send reply
conn.send("Hello from Server".encode())

# Close connection
conn.close()
server.close()




client.py:

import socket

# Create socket
client = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# Connect to server
client.connect(("127.0.0.1", 5000))

print("Connected to server.")

# Send message
client.send("Hello from Client".encode())

# Receive reply
message = client.recv(1024).decode()
print("Server:", message)

# Close connection
client.close()

HOW TO RUN:
Terminal 1:
python3 server.py


Terminal 2: Click the + button in the terminal panel.
python3 client.py
